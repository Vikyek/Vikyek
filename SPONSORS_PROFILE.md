# Hi, I'm Vikyek 👋

I am an independent solo developer and indie author building high-reliability Linux system tools, Arch Linux packaging infrastructure, and token-efficient developer middleware.

Every tool I publish is built out of a direct need for speed, stability, and zero-bloat architecture. I don't build closed-source paywalls, VC-funded telemetry, or abandoned prototypes—I build production-grade, battle-tested utilities that integrate cleanly into daily Linux workflows.

---

### 🛠️ Key Open-Source Projects

- **[`paru-wrapper`](https://github.com/Vikyek/paru-wrapper)** — Enhanced pacman and AUR CLI wrapper featuring a zero-boilerplate modular plugin hook architecture (`/etc/paru-wrapper/hooks.d`), dual-priority local package builds, and clean CLI passthrough. Selected for the **XERJ Corpus Hub** for modular plugin architecture.
- **[`paru-completion-hook`](https://github.com/Vikyek/paru-completion-hook)** & **[`rebuild-check-hook`](https://github.com/Vikyek/rebuild-check-hook)** — Automated dynamic shell completion accelerators and soname library dependency verification hooks that catch broken links before package builds break your system.
- **[`toon-mcp`](https://github.com/Vikyek/toon-mcp)** — High-performance Model Context Protocol server implementing Terse Object Oriented Notation (TOON) to minimize LLM token consumption and reduce API context overhead by up to 40%.
- **[`vlfstatus`](https://github.com/Vikyek/vlfstatus)** — Ultra-lightweight asynchronous status bar daemon for desktop environments (i3, Sway, Waybar) with microsecond latency and zero CPU waste.
- **Linux Resilience & Recovery Suite** — Practical storage, PAM, and kernel recovery utilities including `bcachefs-iso-fabricator`, `btrfs-recovery-tool`, `linux-file-tools`, and `pam-alt-luks-compat`.

---

### 💖 Why Sponsor My Work?

As a solo indie author, I maintain all my repositories, AUR packages (`PKGBUILD`, `.SRCINFO`), manual installation scripts, manpages, and automated test suites myself.

Your sponsorship directly funds:

1. **Dedicated Hardware Testbeds**: Filesystem recovery tools, kernel modules, and PAM/LUKS hooks cannot be tested on paper—they require dedicated SSD test partitions, multi-kernel VMs (vanilla, zen, lts, hardened), and physical test machines to guarantee zero regressions.
2. **AUR & Packaging Infrastructure**: Continuous packaging updates, library ABI tracking, and automated CI build runners to ensure tools build cleanly against bleeding-edge Arch packages.
3. **Sustained Independent R&D**: Keeping my projects 100% open-source, ad-free, and accessible to the entire community without commercial compromises.
4. **Prompt Maintenance & Issue Triage**: Dedicated engineering time to address edge cases, review community PRs, and release timely fixes when upstream package managers or libraries update.

If my tools save you time, keep your Arch updates reliable, or streamline your development environment, joining as a sponsor is the best way to keep this work moving forward.
